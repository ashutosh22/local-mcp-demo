The issue with from mcp.server.fastmcp import FastMCP is that newer versions of the official mcp Python package (v2.0.0 and above) have removed the built-in mcp.server.fastmcp module, causing a ModuleNotFoundError.
The Alternative
Instead of importing from the official SDK namespace, you should install and import FastMCP from the standalone, official fastmcp package:


from fastmcp import FastMCP

Based on this latest structural update from the MCP v2+ SDK design, the entire architectural approach simplifies dramatically. The mcp.server.fastmcp module is completely gone. Instead, the official mcp SDK now includes a native MCPServer class that features a built-in .streamable_http_app() method, which natively generates a FastAPI-compatible ASGI application.
Here is your updated, fully compliant, production-grade weather server code tailored to the modern MCP v2.0+ architecture.

1. Build the Docker Image
Run this command to build your container image locally and tag it as mcp-weather-v2:
bash
docker build -t mcp-weather-v2 .


2. Run the Docker Container
Launch the container in detached background mode (-d) and map port 8000 of the container to port 8000 of your host computer:


docker run -d -p 8081:8081 --name weather-mcp-service mcp-weather-v2

3. Verify it is running properly
Check your running containers to confirm it is healthy:
bash
docker ps

You can also view the application server logs to verify it initialized correctly:
bash
docker logs weather-mcp-service

Step 3: Connect your Local AI Client
Your local custom agent client or desktop client app can now access this server using the endpoint generated by the v2 SDK's streamable HTTP interface.
Add this setup configuration block to your client file:
json
{
  "mcpServers": {
    "weather-stream-service": {
      "url": "http://localhost:8000/mcp"
    }
  }
}
